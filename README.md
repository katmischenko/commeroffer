# Mischenko Edu — сайты Катерины Мищенко

Статические сайты: чистые HTML + CSS + JS, без сборки, зависимостей и бэкенда.
Заливаешь на GitHub → включаешь Pages → всё работает.

## Структура

```
mischenko-site/
├─ index.html              сайт репетитора (главная)
├─ avatar.jpg              иллюстрированный портрет (блок «Обо мне»)
├─ katya.jpg               фотография (запасной вариант)
└─ edu/                    сайт методических пособий
   ├─ edu.css              общие стили библиотеки

   ├─ diagnostika.html     тест-диагностика по информатике (работает)
   ├─ flashcards.html      flash-карточки по физике (работают)
   ├─ simulator.html       игра «Один день из жизни разработчика» (работает)
   ├─ escape-room.html     квест «Побег из лаборатории» (работает)
   ├─ cheatsheets.html     cheat sheets и чек-листы (анонс)
   ├─ workbooks.html       тетради-комиксы (анонс + пример кадров)

```

## Публикация на GitHub Pages

1. Создай репозиторий, например `katmischenko/katmischenko.github.io`
   (или любой другой — тогда сайт будет по адресу `…github.io/<имя-репо>/`).
2. Загрузи в него **содержимое** папки `mischenko-site` (не саму папку,
   а файлы: `index.html`, `avatar.jpg`, `katya.jpg`, папку `edu/`).
3. Settings → Pages → Source: ветка `main`, папка `/ (root)` → Save.
4. Готово:
   - сайт репетитора — `https://<логин>.github.io/`
   - библиотека пособий — `https://<логин>.github.io/edu/`

## Как обновлять библиотеку

Все карточки пособий — в `edu/index.html`, в массиве `ITEMS` внизу файла.
Добавить пособие = добавить объект:

```js
{kind:'пособие', title:'Название', desc:'Описание…',
 subj:'inf', subjName:'информатика',
 st:'ok', stName:'уже доступно', stClass:'st-ok',
 free:true, href:'moy-file.html'}
```

`subj` — одно из: `inf`, `math`, `phys`, `prog`.
`st` — одно из: `ok` (доступно), `soon` (скоро), `work` (в работе).
Фильтры и счётчики обновятся сами.
