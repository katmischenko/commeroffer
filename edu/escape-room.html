Побег из лаборатории

Учебный квест, в котором знания становятся ключом к выходу. Чтобы открыть дверь, нужно пройти несколько испытаний, разобраться в условиях и найти правильные коды.

Что будет внутри

  • Четыре замка и четыре последовательные задачи
  • Задания по информатике и математике
  • Подсказки для тех случаев, когда решение пока не находится
  • Финальная цель — выбраться из лаборатории, применяя логику и знания

Для кого этот материал

  • Тем, кто любит задачи с сюжетом и игровым сценарием
  • Для повторения информатики и математики
  • Для тренировки логики и внимательного чтения условий
