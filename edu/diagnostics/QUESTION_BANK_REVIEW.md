# Аудит банков диагностики Mischenko Edu

Дата аудита: 10.11.2026.

## Структурная проверка

В репозитории находятся 36 банков: 6 направлений по доступным классам, по 15 заданий в каждом — всего 540 заданий.

Для всех банков проверены:
- ровно 15 заданий;
- распределение сложности 5 базовых / 7 средних / 3 сложных;
- уникальность ID и формулировок внутри одного банка;
- наличие темы, навыка, вопроса и объяснения;
- наличие вариантов и корректного индекса правильного ответа для заданий с выбором;
- наличие принимаемых ответов для заданий с кратким ответом;
- соответствие файлов списку профилей.

Также проверяется синтаксис JavaScript основной страницы диагностики.

**Результат:** автоматическая проверка GitHub Actions `Validate diagnostics` завершилась успешно. Это не педагогическая экспертиза содержания.

## Найденные ограничения

1. Все 540 заданий пока остаются черновиками. Требуется проверка фактической правильности ключей, однозначности формулировок, качества дистракторов, объяснений, возрастной уместности и распределения тем.
2. Для Python, HTML/CSS и Figma выбранный опыт пока только записывается в результат. Состав заданий не меняется. Нужны три разные траектории: начинающий / знает основы / есть опыт.
3. Четыре загруженные части пособия относятся к информатике и экзаменационной подготовке ОГЭ/ЕГЭ. Они не являются достаточной программной основой для всех классов и не подтверждают содержание банков по математике, физике, Python, HTML/CSS и Figma.
4. До финальной предметной вычитки необходимо определить, по какой школьной программе строить диагностику: российской, белорусской или другой.

## Замечание к загруженному пособию по информатике, часть 4

В примере по теории игр указаны ходы +1, +3 и +4 при достижении 20 камней.

- В позиции 18 игрок может сразу достичь 21, поэтому позиции, из которых можно выиграть следующим ходом, включают 16, 17, 18 и 19.
- В задаче №20 можно первым ходом перевести игру в позицию 15 из начальных позиций 11, 12 или 14. Два наименьших значения — **11 и 12**. Ответ «11, 14» пропускает корректное значение 12.

Это исправление следует внести в исходное пособие отдельно, если оно будет использоваться как учебный материал. Диагностические банки не должны наследовать эту ошибку.

## Технические исправления интерфейса

- При смене направления поле опыта очищается.
- В результат попадает опыт только для Python, HTML/CSS и Figma.
- Текст вопроса выводится безопасно как текст, а не как HTML.
- Перед запуском проверяется, что загружен массив из 15 заданий.
- В отчёте для копирования используются нормальные переносы строк.

## Follow-up review: cross-grade duplicates and answer keys

- Initial cross-grade scan found 136 repeated question stems, concentrated in Python, HTML/CSS and Figma, plus one duplicate in informatics.
- Rewritten banks: Python 6, 7, 9, 11; HTML/CSS 6, 7, 9, 11; Figma 6, 7, 9, 11. Each of these 12 banks now has its own grade-specific question set and the 5/7/3 difficulty distribution.
- Replaced the repeated informatics 9 logic question with a De Morgan law task.
- Added a strict rule that for choice questions, correctText must exactly equal options[correctIndex]. This found and fixed one mismatch in informatics 6.
- CI now fails if exact question stems recur across grades within a direction.
- Latest successful run: https://github.com/katmischenko/commeroffer/actions/runs/42825640423.
- The changes remove exact repeats and structural answer-key mismatches. They do not prove that all explanations, distractors, subject facts or curriculum placement are pedagogically correct.


## Первые банки под российскую ФРП

Созданы 18 отдельных черновиков на 270 заданий:
- математика 6–9 классов — базовый уровень;
- физика 7–9 классов — базовый уровень;
- физика 10–11 классов — базовый и углублённый уровни;
- информатика 7–9 классов — базовый уровень;
- информатика 10–11 классов — базовый и углублённый уровни.

Каждый вариант содержит метаданные программы, года, класса, источника и статуса teacher_review_draft. Эти файлы загружаются только при выборе соответствующей российской программы и учебного года 2026/2027. Они не имеют статуса reviewed/ready: необходима независимая предметная проверка, проверка уровня сложности, правильности всех ключей и полноты покрытия ФРП.

Для информатики 6 класса российская федеральная программа не предлагается: требуется локальная программа школы или конкретный учебник. Для информатики 6 класса российская федеральная программа не предлагается: требуется локальная программа школы или конкретный учебник.
