# Диагностика Mischenko Edu — статус реализации

Обновлено: 10.11.2026

## Подтверждено и сохранено
- Направления и диапазоны классов: информатика 6–11, физика 7–11, математика 6–9, Python / HTML-CSS / Figma 5–11.
- Для дополнительных направлений обязателен вопрос об опыте: начинаю / знаю основы / есть опыт.
- Требование 15 вопросов на одну попытку.
- Матрицы тематического покрытия и навыков.
- Структура отчёта ученику и преподавателю, самооценка уверенности, повторные попытки, PDF.
- Спецификация: `diagnostic-spec.md`.
- Подготовлен D1 Worker: `worker.js`.
- Подготовлена схема архива: `schema.sql`.
- Подготовлена инструкция развертывания: `DEPLOY.md`.
- Подготовлена защищённая страница просмотра архива: `archive.html`.

## Пока не готово к публичному запуску
- Основная страница `../diagnostika.html` ещё не заменена новой системой.
- Банк из 15 проверенных вопросов для каждого профиля «направление × класс» ещё не собран и не прошёл предметную вычитку.
- Новый Worker ещё не развернут в Cloudflare; текущий Worker не был изменён из этой среды.
- D1 ещё не создана / не привязана к Worker.
- Секрет `ADMIN_TOKEN` ещё не установлен в Cloudflare.
- Политика конфиденциальности и срок хранения данных не утверждены.
- Не проведён браузерный тест полного сценария на опубликованной GitHub Pages.

## Почему нельзя считать архив уже работающим
Файлы Worker и SQL в GitHub — исходный код и миграция, а не развернутая инфраструктура. До подключения D1 и публикации Worker endpoint не будет сохранять попытки в постоянную базу. Текущий Telegram Worker известен по адресу, но доступ к его панели Cloudflare и исходному коду не предоставлен.

5. Подключить архив, сравнение повторных попыток и экспорт PDF.
6. Протестировать все направления, классы, мобильный интерфейс, ошибки сети и защиту от дублей.
7. Утвердить текст согласия, срок хранения и процедуру удаления до публичного запуска.

## Не использовать в публичном маркетинге до завершения пунктов выше
Не писать, что диагностика уже охватывает все направления/классы, хранит историю в облаке или автоматически отправляет полный отчёт, пока это не проверено на опубликованной версии.
