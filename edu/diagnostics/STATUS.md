# Статус системы диагностики Mischenko Edu

Обновлено: 2026-11-10.

## Реализовано в GitHub
- Спецификация системы и матрицы тем по всем шести направлениям.
- Cloudflare Worker с проверкой входных данных, сохранением попытки в D1, защитой от повторной записи и retryable Telegram outbox (pending/sending/sent, повтор после сетевой ошибки, перехват зависшего статуса).
- SQL-схема базы данных и инструкция по Cloudflare deployment.
- Закрытый экран архива с фильтрацией, просмотром ответов и печатью в PDF.
- Черновой банк из 15 заданий по информатике для 6 класса.
- Страница предпросмотра `diagnostika-v2-preview.html`: выбор профиля, проверка доступности банка, прогресс, возврат назад, ответ «не знаю», пропуск, уверенность, разбор, итоговый отчёт и отправка в Worker.
- Реестр всех 36 профилей в `profiles.json`.

## Не готово к публичному запуску
- Только один из 36 банков существует, он ещё требует педагогической вычитки.
- Остальные 35 банков (525 заданий) не созданы.
- Предпросмотр использует только профиль «Информатика, 6 класс»; остальные профили показывают сообщение о недоступности, не подменяя их чужими заданиями.
- Не проверены полные POST/D1/Telegram сценарии на отдельной тестовой конфигурации.
- Worker в Cloudflare необходимо обновить после изменений его исходника; GitHub и Cloudflare не синхронизируются автоматически.
- Архив/PDF не проверен на реальных записях.
- Не утверждены срок хранения и окончательный текст согласия.
- Нужны проверки mobile, доступности, сетевых повторов и корректности данных.
