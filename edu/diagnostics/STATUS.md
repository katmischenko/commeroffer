# Диагностика Mischenko Edu — статус реализации

Обновлено: 10.11.2026

## Подтверждено
- Пользователь сообщила, что проверка публичного Worker endpoint прошла успешно и всё работает.
- По результату пользовательской проверки Worker распознаёт подключённую D1 (ожидаемый ответ корневого endpoint — `database: true`).
- В репозитории сохранены спецификация, тематические матрицы 36 профилей, SQL-схема, Worker, инструкция развертывания и экран архива.
- Структура профилей: информатика 6–11, физика 7–11, математика 6–9, Python / HTML-CSS / Figma 5–11.
- Для Python / HTML-CSS / Figma требуется учитывать опыт ученика.
- Требование одной попытки: ровно 15 вопросов.

## Обновление Worker в GitHub
- В коммите `1de7aa3072de32458a9dc3a31df6c6c7276e639c` исправлена идемпотентность отправки: повторный POST с тем же `attemptId` больше не создаёт повторное Telegram-уведомление.
- Это изменение находится в GitHub, но его ещё нужно отдельно опубликовать в Cloudflare Worker. GitHub и развернутый Worker — разные версии кода.
- При повторном запросе с уже сохранённым `attemptId` Worker возвращает `duplicate: true`, не отправляя второе уведомление.

## Не считать готовым к публичному запуску
- Основная страница `../diagnostika.html` пока содержит старую диагностику по информатике на 8 вопросов.
- Добавлен первый черновой банк `question-bank-informatics-6.json`: 15 заданий для информатики 6 класса (5 базовых, 7 средних, 3 повышенной сложности). JSON и ключи прошли техническую проверку на структуру, количество, отсутствие дублирующихся вариантов и допустимые индексы ответов; предметная вычитка преподавателем ещё требуется.
- Остальные 35 профилей и ещё 525 заданий пока не созданы.
- Новая страница с выбором направления, класса и опыта, 15 вопросами, возвратом назад, уверенностью и итоговым отчётом ещё не внедрена.
- End-to-end отправка Telegram и корректное сохранение реальной попытки в D1 ещё не тестировались в рамках полного прохождения новой страницы.
- Экран архива `archive.html` и PDF/печать не проверены на реальных записях.
- Текст согласия, срок хранения и процедура удаления требуют окончательного утверждения до публичного запуска.

## Следующие шаги
1. Продолжить банк по остальным профилям; для информатики использовать загруженное авторское пособие там, где темы раскрыты, а для остальных предметов отдельно сверять учебное содержание.
2. Провести педагогическую вычитку уже созданного профиля информатики 6 класса.
3. Реализовать новую страницу диагностики и подключить банк.
4. Сверить формат отправляемого payload с Worker и проверить валидацию.
5. Повторно опубликовать актуальный `worker.js` в Cloudflare.
6. Провести отдельный тест сохранения в D1 и Telegram с явного разрешения пользователя, используя только тестовые данные.
7. Проверить архив, печать/PDF, повторные попытки, мобильную версию и сетевые ошибки.
8. Утвердить понятное согласие, срок хранения и порядок удаления.

## Ограничения
Не сообщать ученикам и родителям, что новая диагностика уже запущена для всех направлений, что архив полностью проверен или что все 540 заданий прошли предметную вычитку. До завершения тестов использовать формулировку «в разработке».
